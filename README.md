# Trading Bot Playground

Personal repository for learning, experimenting, and building algorithmic trading bots.

## Goals

- Learn how trading bots work
- Connect to exchanges using APIs
- Download and store historical market data
- Backtest trading strategies
- Automate trades
- Build dashboards and metrics
- Experiment with AI and automation applied to trading

---

## Technologies

- Python
- CCXT
- Pandas
- NumPy
- SQLite / PostgreSQL
- Matplotlib
- Exchange APIs (BingX, Binance, etc.)
